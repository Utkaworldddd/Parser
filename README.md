# Parser

Десктопное приложение для сбора данных с сайтов. Пользователь вводит ссылку, страница открывается внутри окна программы, он кликает по одному нужному элементу (цена, заголовок, ссылка), и программа находит на странице все похожие элементы, сохраняет их в базу и отправляет в Telegram.

## Стек

- Python 3.11+
- PyQt6 и PyQt6-WebEngine — окно и встроенный браузер
- SQLite (модуль `sqlite3` из стандартной библиотеки) — хранение
- Telegram Bot API через `requests` — отправка результатов

## Как это выглядит для пользователя

1. Вводит адрес сайта в строку сверху и нажимает «Открыть».
2. Страница загружается в центральной части окна, по ней можно ходить как в обычном браузере.
3. Нажимает кнопку «Выбрать элемент». Программа переходит в режим выбора: элемент под курсором подсвечивается рамкой, переходы по ссылкам отключены.
4. Кликает по одному элементу, например по цене первого товара.
5. Программа подсвечивает все похожие элементы на странице и показывает их текст в таблице справа.
6. Пользователь даёт набору название («Цены») и нажимает «Сохранить».
7. По кнопке «Отправить в Telegram» собранные данные уходят в чат с ботом.

## Окно

Одно главное окно, разделённое на три части:

- сверху — строка адреса, кнопки «Открыть», «Назад», «Выбрать элемент»;
- слева и по центру — браузер (`QWebEngineView`);
- справа — панель с таблицей найденных значений, полем для названия, кнопками «Сохранить» и «Отправить в Telegram».

Отдельно два небольших окна: «Настройки» (токен бота и chat id) и «История» (список прошлых сборов из базы с возможностью открыть любой и посмотреть значения).

## Как работает выбор элемента

Это главная часть программы. Python не видит страницу напрямую, поэтому вся работа с элементами идёт через JavaScript, который программа вставляет в загруженную страницу.

**Связь Python и страницы.** Используется `QWebChannel`. В Python создаётся объект-мост с методом, принимающим данные, он регистрируется в канале, а на странице подключается `qwebchannel.js`. После этого скрипт на странице может вызвать метод Python-объекта и передать ему строку с результатом.

**Режим выбора.** При нажатии «Выбрать элемент» на страницу через `page().runJavaScript()` вставляется скрипт, который:

- на `mouseover` рисует рамку вокруг элемента под курсором, на `mouseout` убирает;
- на `click` отменяет стандартное действие (`preventDefault`, `stopPropagation`), чтобы ссылка не открылась;
- строит для кликнутого элемента CSS-селектор;
- отправляет селектор в Python через мост.

**Построение селектора.** От кликнутого элемента поднимаемся вверх по родителям до `body` и для каждого уровня записываем имя тега и его классы, например `div.card > div.card-body > span.price`. Номера элементов (`nth-child`) специально не добавляются: тогда селектор подходит не только к тому элементу, по которому кликнули, а ко всем с такой же структурой — это и есть «похожие элементы».

Если у элемента нет классов, остаётся просто тег. Если селектор получился слишком общий и находит сотни лишних элементов, путь берётся длиннее (больше родителей); если находит только один — верхние уровни убираются по одному, пока совпадений не станет больше.

**Сбор значений.** С готовым селектором выполняется `document.querySelectorAll(selector)`, у каждого найденного элемента берётся `innerText`. Для ссылок дополнительно берётся `href`, для картинок — `src`. Пустые строки пропускаются. Результат возвращается в Python как JSON-строка, там разбирается через `json.loads` и выводится в таблицу.

## База данных

Файл `parser.db` создаётся рядом с программой при первом запуске.

Таблица `tasks` — один сбор:

| поле | тип | что хранит |
|---|---|---|
| id | INTEGER PRIMARY KEY | номер |
| name | TEXT | название, которое ввёл пользователь |
| url | TEXT | адрес страницы |
| selector | TEXT | CSS-селектор |
| created_at | TEXT | дата и время |

Таблица `items` — собранные значения:

| поле | тип | что хранит |
|---|---|---|
| id | INTEGER PRIMARY KEY | номер |
| task_id | INTEGER | к какому сбору относится |
| value | TEXT | текст элемента |
| link | TEXT | ссылка, если есть |

Таблица `settings` — пары ключ/значение для токена и chat id.

Селектор хранится для того, чтобы сбор можно было повторить: открыть ту же страницу и снова забрать данные тем же селектором без нового клика.

## Telegram

Пользователь создаёт бота через @BotFather, получает токен и вводит его в настройках вместе со своим chat id.

Отправка — обычный POST-запрос на `https://api.telegram.org/bot<токен>/sendMessage` с параметрами `chat_id` и `text`. Сообщение собирается так: название сбора, адрес страницы, дальше значения по одному на строку.

У Telegram ограничение 4096 символов на сообщение, поэтому длинный список режется на несколько сообщений. Если значений очень много (больше 200), вместо текста отправляется CSV-файл методом `sendDocument`.

Запрос выполняется в отдельном потоке (`QThread`), чтобы окно не зависало, пока идёт отправка. При ошибке (неверный токен, нет интернета) показывается окно с текстом ошибки.

## Структура файлов

```
Parser/
  main.py          запуск приложения
  window.py        главное окно и обработчики кнопок
  browser.py       встроенный браузер, мост QWebChannel, вставка скриптов
  picker.js        скрипт выбора элемента и построения селектора
  database.py      создание таблиц, сохранение и чтение
  telegram.py      отправка сообщений и файлов
  settings.py      окно настроек
  history.py       окно истории
  requirements.txt
```

## Порядок разработки

1. Окно со строкой адреса и браузером, загрузка страницы по ссылке.
2. Подсветка элемента под курсором (только JavaScript, без связи с Python).
3. Мост `QWebChannel`: по клику в Python приходит тег элемента.
4. Построение селектора и поиск похожих элементов.
5. Таблица с результатами в правой панели.
6. База: создание таблиц, сохранение сбора, окно истории.
7. Настройки и отправка в Telegram.
8. Обработка ошибок, проверка на нескольких разных сайтах.

## Ограничения

- Собирается только то, что есть на открытой странице. Переход по страницам каталога (пагинация) не автоматизирован.
- Если сайт подгружает товары при прокрутке, нужно сначала прокрутить вручную, потом выбирать элемент.
- На сайтах, где классы генерируются случайно при каждой сборке, сохранённый селектор может перестать работать.
- Содержимое внутри `iframe` не выбирается.
- Некоторые сайты показывают встроенному браузеру капчу.
